# 🐳 Docker Compose Notes

## 📖 58-1: Introduction To Docker Compose

### What is Docker Compose?

Docker Compose is a tool that allows us to define and manage multiple Docker containers using a single YAML configuration file.

Instead of running multiple `docker run` commands manually, we can define all services in one `docker-compose.yml` file and start them together.

### Why Use Docker Compose?

- Manage multiple containers easily
- Simplify development workflow
- Store container configuration in code
- Start and stop all services with a single command
- Create isolated networks automatically

### Example Scenario

A typical MERN application contains:

- Frontend (Next.js/React)
- Backend (Node.js/Express)
- Database (MongoDB/PostgreSQL)

Without Docker Compose:

```bash
docker run ...
docker run ...
docker run ...
```

With Docker Compose:

```bash
docker compose up
```

### Common Docker Compose Commands

Start services:

```bash
docker compose up
```

Build and start:

```bash
docker compose up --build
```

Run in background:

```bash
docker compose up -d
```

Stop services:

```bash
docker compose down
```

View running services:

```bash
docker compose ps
```

View logs:

```bash
docker compose logs
```

# 📝 58-2: Creating First Docker Compose File

### Create docker-compose.yml

```yaml
version: "3.9"

services:
  app:
    image: nginx
    ports:
      - "8080:80"
```

### Start Compose

```bash
docker compose up
```

### Check Running Containers

```bash
docker ps
```

### Stop Services

```bash
docker compose down
```

### Understanding the Structure

```yaml
services:
```

Defines all containers.

```yaml
app:
```

Service name.

```yaml
image: nginx
```

Image used for container creation.

```yaml
ports:
  - "8080:80"
```

Maps host port to container port.

# 🐘 58-3: Creating Service For PostgreSQL Container In Docker Compose File

### PostgreSQL Service

```yaml
services:
  postgres:
    image: postgres:17
    container_name: postgres-db

    environment:
      POSTGRES_USER: admin
      POSTGRES_PASSWORD: secret
      POSTGRES_DB: mydb

    ports:
      - "5432:5432"

    volumes:
      - postgres-data:/var/lib/postgresql/data
```

### Create Named Volume

```yaml
volumes:
  postgres-data:
```

### Explanation

| Property       | Purpose               |
| -------------- | --------------------- |
| image          | PostgreSQL image      |
| container_name | Container name        |
| environment    | Database credentials  |
| ports          | Expose PostgreSQL     |
| volumes        | Persist database data |

### Verify Database

```bash
docker compose up -d
```

Check:

```bash
docker ps
```

# 🚀 58-4: Creating Service For Node-Express Container In Docker Compose File

### Dockerfile

```dockerfile
FROM node:20-alpine

WORKDIR /app

COPY package*.json ./

RUN npm install

COPY . .

EXPOSE 5000

CMD ["npm", "start"]
```

### Compose Service

```yaml
services:
  backend:
    build: .

    container_name: express-api

    ports:
      - "5000:5000"

    environment:
      PORT: 5000
      DATABASE_URL: postgres://admin:secret@postgres:5432/mydb

    depends_on:
      - postgres
```

### Important

```yaml
depends_on:
  - postgres
```

Ensures PostgreSQL container starts before backend container.

### Build and Run

```bash
docker compose up --build
```

### View Logs

```bash
docker compose logs backend
```

# ⚡ 58-5: Creating Service For Next.js Frontend Container In Docker Compose File

### Next.js Dockerfile

```dockerfile
FROM node:20-alpine

WORKDIR /app

COPY package*.json ./

RUN npm install

COPY . .

EXPOSE 3000

CMD ["npm", "run", "dev"]
```

### Frontend Service

```yaml
services:
  frontend:
    build: ./frontend

    container_name: next-app

    ports:
      - "3000:3000"

    depends_on:
      - backend

    environment:
      NEXT_PUBLIC_API_URL: http://backend:5000
```

### Full Architecture

```text
Frontend (Next.js)
        |
        ↓
Backend (Node.js/Express)
        |
        ↓
PostgreSQL
```

### Complete Compose Structure

```yaml
version: "3.9"

services:
  postgres:
    image: postgres:17
    environment:
      POSTGRES_USER: admin
      POSTGRES_PASSWORD: secret
      POSTGRES_DB: mydb

  backend:
    build: ./backend
    ports:
      - "5000:5000"
    depends_on:
      - postgres

  frontend:
    build: ./frontend
    ports:
      - "3000:3000"
    depends_on:
      - backend

volumes:
  postgres-data:
```

### Run Entire Application

```bash
docker compose up --build
```

### Access Application

Frontend:

```text
http://localhost:3000
```

Backend:

```text
http://localhost:5000
```

PostgreSQL:

```text
localhost:5432
```

# 🎯 Key Takeaways

- Docker Compose manages multiple containers together.
- Services are defined inside `docker-compose.yml`.
- `depends_on` controls startup order.
- Volumes persist database data.
- Networks are created automatically.
- A full-stack application can be run using a single command:

```bash
docker compose up --build
```
