# 59-1: Introduction to Reverse Proxy

## What is a Reverse Proxy?

A Reverse Proxy sits between clients and backend servers.

```text
Client
   ↓
Nginx Reverse Proxy
   ↓
Backend Server
```

Users communicate with Nginx, and Nginx forwards requests to backend services.

## Benefits

- Security
- SSL Termination
- Load Balancing
- Caching
- Hide Internal Servers
- Better Performance

## Example

User visits:

```text
https://myapp.com
```

Nginx forwards request to:

```text
http://localhost:5000
```

# 59-2: Reverse Proxy Hands-on

## Install Nginx

```bash
sudo apt update
sudo apt install nginx -y
```

## Basic Reverse Proxy Configuration

```nginx
server {
    listen 80;

    server_name myapp.com;

    location / {
        proxy_pass http://localhost:5000;

        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

## Test Configuration

```bash
sudo nginx -t
```

## Reload Nginx

```bash
sudo systemctl reload nginx
```

# 59-3: Understanding Load Balancer and Hands-on Implementation

## What is Load Balancing?

Load balancing distributes traffic among multiple servers.

```text
            Nginx
              |
    ---------------------
    |         |         |
 App-1     App-2     App-3
```

## Benefits

- High Availability
- Scalability
- Fault Tolerance
- Better Performance

## Nginx Load Balancer

```nginx
upstream backend {
    server app1:5000;
    server app2:5000;
    server app3:5000;
}

server {
    listen 80;

    location / {
        proxy_pass http://backend;
    }
}
```

# 59-5: How To Write a Dockerfile Smartly

## Bad Dockerfile

```dockerfile
FROM node

COPY . .

RUN npm install

CMD ["npm", "start"]
```

Problems:

- Large image size
- Poor caching
- Slow build

## Better Dockerfile

```dockerfile
FROM node:20-alpine

WORKDIR /app

COPY package*.json ./

RUN npm install

COPY . .

EXPOSE 5000

CMD ["npm", "start"]
```

## Best Practice

### Use .dockerignore

```text
node_modules
.git
.env
```

### Use Smaller Base Images

```dockerfile
FROM node:20-alpine
```

### Layer Optimization

Copy package files first.

```dockerfile
COPY package*.json ./
RUN npm install
```

# 59-6: Write Docker Compose and Nginx Config File For Production

## docker-compose.yml

```yaml
version: "3.9"

services:
  frontend:
    image: my-frontend

  backend:
    image: my-backend

  nginx:
    image: nginx
    ports:
      - "80:80"

    depends_on:
      - frontend
      - backend
```

## Production Nginx Config

```nginx
server {

    listen 80;

    location / {
        proxy_pass http://frontend:3000;
    }

    location /api {
        proxy_pass http://backend:5000;
    }
}
```

## Run Application

```bash
docker compose up -d
```

# 59-7: Deep Dive into CI/CD: Building GitHub Actions Workflows

## What is CI/CD?

### CI (Continuous Integration)

Automatically:

- Build
- Test
- Verify code

### CD (Continuous Deployment)

Automatically deploy application.

---

## GitHub Actions Workflow

Create:

```text
.github/workflows/deploy.yml
```

## Example Workflow

```yaml
name: Deploy App

on:
  push:
    branches:
      - main

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
      - uses: actions/checkout@v4

      - name: Setup Node
        uses: actions/setup-node@v4

      - name: Install Dependencies
        run: npm install

      - name: Run Tests
        run: npm test
```

## Deployment Step

```yaml
- name: Deploy
  run: |
    ssh user@server "cd app && docker compose up -d"
```
